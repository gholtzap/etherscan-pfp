This chrome extension attaches PFPs of various kinds to ETH Addresses when browsing Etherscan.io


Name on chrome web store : Etherscan ETH Address Icon

How to manually upload:
1. Download this repo to a dir
2. Navigate to 'chrome://extensions/' on chromium browser
3. 'Load Unpacked'
4. Select the dir you saved this repo to
